# Xiaoli Trae Card C3

适用于本次 USB 识别到的 ESP32-C3、8MB Flash、ES8311、ST7789 设备。
不能仅凭同为 C3 就给其他板子烧录此配置。

## 硬件来源与验证状态

配置来自设备原厂 `trae_card` 1.0.0（2026-08-11，ESP-IDF 5.5.3）的静态分析。
原固件 SHA256：`d7100cc54c0d8762a272a0ff75645a115fa79e376d7652d07df9e07e34c7a279`。
完整 8MB 备份位于仓库忽略目录 `backups/c3-4c11ae3250c8/original-20260929.bin`。
备份可能含设备身份和配网数据，不应提交 Git。

应用 DROM 配置表地址为 `0x3c108cd8`：

| 字段偏移 | 含义 | 值 |
|---|---|---|
| 0 / 2 | LCD 宽 / 高（uint16） | 240 / 320 |
| 8 / 12 | LCD MOSI / SCLK | GPIO9 / GPIO8 |
| 16 / 20 / 24 / 28 | LCD CS / DC / RESET / 背光 | GPIO1 / GPIO20 / -1 / GPIO21 |
| 32 | SPI 时钟 | 80MHz |
| 36 | ADC 按键通道 | ADC1 channel 0（GPIO0） |
| 60 / 64 | ES8311 I²C SDA / SCL | GPIO10 / GPIO7 |
| 68 / 72 / 76 | I²S MCLK / BCLK / WS | GPIO6 / GPIO5 / GPIO3 |
| 80 / 84 / 88 | I²S DOUT / DIN / PA | GPIO2 / GPIO4 / -1 |

音频初始化函数 `0x42013108` 读取上述配置；`0x42012fbc` 设置 I²S，
原厂初始采样率为 16kHz。I²C 地址 0x30 为 codec 库使用的 8-bit 地址，
总线探测使用 7-bit 地址 0x18。

屏幕初始化函数 `0x420121c6`，专用寄存器序列位于 `0x3c1d99cc`。
按键初始化函数 `0x42012abe`，三个 ADC 电压窗口位于 `0x3c1d9ae8`：
0–150、150–447、447–1900 mV。已通过逐键日志确认：右侧从上到下依次为 ADC 0、1、2。
GPIO9 已用于屏幕，不能使用通用 C3 板子的 GPIO9 BOOT 按键配置。

这些数值已由原固件交叉核对，仍需要烧录后的收音、播放、屏幕与按键实测。
固件没有烧写 eFuse，也没有推测额外的电源保持 GPIO。
原固件包含 CW2017 电量计线索。当前适配在 I²C 地址 0x63 探测芯片，
每 30 秒读取一次 SOC 并在右上角显示图标与百分比；探测或读数失败时留空。
充电状态的接线尚未确认，因此不显示充电标记。

## 功能

- 16kHz ES8311 双向音频，复用小李服务端的识别、对话和语音播放。
- ESP Wake Word / WakeNet9s “你好小智”唤醒。
- ST7789 240×320 显示，PWM 背光。
- 卡通头像使用 21 种现有情绪与倾听、说话状态；头像资源从 Flash 映射读取，制作文件见 `artwork/README.md`。
- 右侧最上（ADC 0）：音量加；中间（ADC 1）：音量减；最下（ADC 2）：
  点击切换对话，长按进入配网。
- 调节音量时右侧显示竖向音量条和百分比，2.5 秒后自动收起；用户已确认显示正常。
- USB Serial/JTAG 控制台，保留 GPIO18/19 作为 USB。
- 8MB 分区，双 OTA 应用槽和独立资源区。

## 构建

在仓库根目录运行 `./flash.sh --profile c3 --build-only`。
烧录和回滚说明见 `docs/flash-guide.md`。

## 四颗实体按键的核对

原固件只注册三个 ADC 软件按键。第四颗左侧键是配套产品资料所述的独立硬件
电源键，不属于这些软件按键，不能绑定为 MCU 的普通按键事件。
三个 ADC 按键按下时输出 `ADC button N pressed` 日志，便于核对实体键。
`Xiaoli Assistant -> Xiaoli Trae C3 button mapping` 可配置对话、音量减、音量加
对应的索引；索引必须各不相同，否则编译报错。本设备已实测确认从上到下为 0/1/2。

用户确认布局为左侧电源；右侧最上音量加、中间音量减、最下唤醒。
最下键点击切换对话，长按配网。实体键与 ADC 索引已按上、中、下的按压顺序确认。

### 左侧电源键调查

原厂按键指引字符串位于 `0x3c0f6a88`，内容为“电源键 / 开机：短按0.5s /
关机：长按2.0s”。原厂 ADC 驱动仅注册三个功能键。
实测右侧三个键约为 3、303、604mV，松开约 2878mV；用户操作左键时未观察到
ADC 电压变化或复位。用户记得原系统可用左键使屏幕亮灭。
用户随后实测确认长按左键可关机，关机后 USB 串口设备从系统中消失。
后续找到 FoloToy 官方资料，其 GPIO、外设型号和按键电压窗口与本设备一致：

- [硬件开发指南 §3.2](https://github.com/FoloToy/ai-passport/blob/main/docs/hardware-design/AI_HARDWARE_DEVELOPMENT_GUIDE.zh_CN.md#32-bsp-%E4%B9%8B%E5%A4%96%E7%9A%84%E4%BA%A7%E5%93%81%E6%8E%A5%E5%8F%A3)
  说明电源键独立控制硬件电源。
- [产品规格](https://github.com/FoloToy/ai-passport/blob/main/docs/hardware-design/specifications.zh_CN.md)
  区分电源键开关机与自动息屏后通过功能键唤醒。

现有公开硬件接口未提供左键事件；左键单击息屏不能仅通过调整本固件的按键映射实现。
如必须使用左键，需要确认实物电路是否能增加 MCU 可读取的信号。
用户明确保留左键方案，因此未增加音量键长按或自动息屏替代行为。
本次仅交付音量条；未接入的息屏代码已撤去，避免将尚不可用的功能留作完成状态。
临时连续电压采样代码已移除，保留按键按下时的电压日志。
